# Assets and dependencies

- The vector demo item icons, block textures, placeholder character skin and neutral SVG logo in this download are original template artwork. The download does not include extracted Minecraft game textures, default Steve textures, player-specific skins, the original server's chicken logo or its old favicon.
- The sky background is supplied with the template. Replace it through `site.config.json` if using your own art.
- Poppins is distributed under the SIL Open Font License. Its complete licence and copyright notice are in `public/assets/fonts/OFL.txt`.
- Next.js, React, React DOM and Three.js are MIT-licensed projects. TypeScript and Sharp use Apache-2.0 licences. Lucide icons use the ISC licence. Their installed package licence files remain applicable. The dependency tree is pinned in `package-lock.json`.
- Minecraft player skins and avatars, when requested by a customer, are fetched at runtime from Mojang or Geyser. Those third-party services and the player's selected skin are separate from the bundled original demo artwork.
- Tebex handles checkout; Discord is an external community service. Service names and logos are used to identify their integrations, not to imply endorsement.

No API keys, live customer records, payment records, production environment files or server access information are supplied in this download.
