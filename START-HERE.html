Your server. Your store.
Start here.

Preview the website in a few steps. Connect your own Tebex account when you are ready to go live.

1. Install Node.js

Install Node.js 24 from nodejs.org. If it is already installed, run node --version to check.

2. Extract and launch

Windows: extract the ZIP and double-click START-WINDOWS.cmd.

macOS/Linux: open a terminal in the extracted folder and run sh start-here.sh.

Answer the setup questions, or press Enter to keep the demo settings. The first run installs the required packages.

3. Open your preview

When the terminal says Ready, open http://localhost:3100. The included server website is at /server.

Keep the terminal open while previewing. Press Ctrl+C to stop.

4. Add your branding and Tebex account

Edit site.config.json for public details. The setup wizard creates .env.local for private credentials. Read SETUP.txt for the live-store and hosting steps.

npm run doctor
npm run build
npm start

This is a standalone Node.js website, not a file to upload to Tebex's theme editor. The demo cannot take payments. No seller API keys are included.
